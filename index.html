概要・制度説明
本マニュアルはGBの特定技能申請業務に関わる全スタッフ（行政書士・補助者）向けの業務手順書です。
特定技能申請業務とは
登録支援機関からオーダーを受注し、書類作成・申請・在留カード納品までを担う業務です。

業務フロー
役割分担
行政書士の担当業務
  • アサイン：補助者への案件割り振り
  • 最終確認：申請書類の最終チェック・差し戻し
  • 申請：オンラインまたは窓口申請
  • 入管対応：審査中の照会への対応
  • 交付対応：在留カードの受取（郵送 / 窓口）
  • 納品：登録支援機関への在留カード納品
  • 判断業務：法的判断が必要な情報の参照・確認
補助者の担当業務
  • データ整理：申請人・所属機関書類データの整理
  • RAKUVISAアップ：PDFデータのアップロード（RAKUVISA案件）
  • Gドライブ保存：PDFデータの保存（dekisugi案件）
  • 書類作成：RAKUVISA / dekisugiを使った書類作成
  • 自己確認：作成完了後の一次チェック
  • kintone確認：登録支援機関とのやり取り確認
⚠️
補助者は申請行為を行えません。申請（オンライン入力・窓口持参）は必ず行政書士が担当します。

申請区分・在留資格
特定活動（移行準備）
特定技能1号への在留資格変更が在留期間満了までに間に合わない場合の移行準備として使う在留資格です。
⚠️
変更申請のみ対応。認定申請・更新申請は存在しません。
主な要件
  • 在留期間満了の7日前までに特定技能1号への変更申請ができない合理的な理由があること
  • 技能試験・日本語試験に合格していること（技能実習2号良好修了者は免除）
  • 受入機関が支援計画を作成し適切に支援を行うことが見込まれること

品質管理
行政書士による最終確認のポイント
「どの項目を・なぜ確認するか」を決める判断基準と考え方です。補助者が確認依頼を出す際の参考にもなります。
💡
最終確認はすべての項目を機械的にチェックするのではなく、「確認コストに見合うリスク低減効果があるか」で判断します。重点的に確認すべき項目に集中することで、質と効率を両立させます。
確認すべき項目かどうかの判断軸（3つの視点）

以下の3軸を総合して「この項目は自分が確認すべきか否か」を判断します。どれか1つが極端に高い場合は、単独でも確認の必要性を示します。

⚡
① 影響の大きさ
万が一、誤った内容で提出した場合にどれほどの影響があるか。
不許可・再申請・申請人への不利益・入管との関係悪化など、取り返しのつかないミスにつながる項目は優先的に確認する。
影響大 → 必ず確認 影響中 → できれば確認 影響小 → 省略可能
🔄
② リカバリーの可否
間違いが発覚したとき、どれくらい容易に修正・対処できるか。
提出後に訂正不可・不許可通知後の対応が困難な項目は、事前確認の優先度が上がる。
修正不可 → 必ず確認 修正困難 → できれば確認 修正容易 → 省略可能
⚠️
③ ミスが発生しやすいか
入力方法の複雑さ・担当者のスキル・作業の繁雑さなどから、実際にミスが起きやすい項目かどうかを判断する。
手入力が多い・選択肢が紛らわしい・条件分岐が複雑な箇所は確認の優先度が高い。
ミス率高 → 必ず確認 ミス率中 → できれば確認 ミス率低 → 省略可能
＋ 経験則による補正

3軸の客観的な判断に加え、自分自身が実際に作成・確認作業を行なってきた経験を加味します。

経験則が活かされる場面
例1
「この申請区分では○○の書類で記載ミスが出やすい」という実績
過去に何度かミスが発生した箇所は、3軸の評価より重点的に確認する。
例2
担当補助者ごとの得意・不得意の傾向
担当者の習熟度によって確認の深度を調整する。経験が浅い時期は全体的に確認を厚くする。
例3
特定の取引先・案件パターンで繰り返す典型ミス
同じ取引先や分野で何度も出るエラーパターンは、チェックリストに追加するか重点確認項目に昇格させる。
例4
入管窓口・システムの仕様変更に伴う新たなリスク
制度改正・RAKUVISA/dekisugi のアップデート直後は、従来は問題なかった箇所でもミスが増える。移行期は確認を強化する。
確認優先度の目安（組み合わせによる判断）
影響の大きさリカバリーミス率確認優先度対応方針
大不可〜困難高〜低最優先行政書士が必ず自ら確認
大可能高高行政書士が確認。修正フローも整備しておく
中不可〜困難高〜中高行政書士が確認
中可能中中補助者がダブルチェック後、行政書士は抜き取り確認
小可能低省略可補助者のチェックで完結。行政書士確認は任意
「確認しない」という判断も重要
✅
確認に使う時間は有限です。影響が小さく・修正が容易で・ミスが起きにくい項目への確認コストは、より重要な箇所へ集中するための「省略判断」として位置づけます。
  • システムが自動入力する項目（RAKUVISAの自動反映フィールドなど）は、出力後の確認よりソース（パスポート・在留カード）との照合を優先する
  • 添付書類の有無チェックは、補助者が作成した書類チェックリストを信頼し、抜き取り確認で十分
  • 書式・フォント・レイアウトなどの見栄えは、入管の審査対象外のため確認優先度は最低位
  • 同一情報が複数箇所に転記される場合は、元情報（パスポート等）だけを確認し、転記先の全箇所チェックは省略可能
⚠️
このページに記載した判断基準は固定ルールではありません。新しい経験・ミス事例・制度変更に合わせて随時アップデートしてください。

必要書類が全て作成されているか
✓

✓
納品フォルダの命名規則が正しいか（日付・案件番号・登録支援機関名・人数）
✓
申請人の氏名・生年月日・国籍に誤りがないか（パスポート照合）
